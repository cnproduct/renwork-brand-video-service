# Brandkit

A comprehensive brand system packaging skill that transforms a logo and brand concept into a complete, professional brand identity system with specifications and application mockups.

## Core Capabilities

### 1. Brand Concept Articulation & Visual Positioning
- Articulate brand essence, mission, vision, and personality in design language
- Define visual positioning: minimalist vs. expressive, corporate vs. friendly, premium vs. accessible
- Create a brand voice and tone guide aligned with visual identity
- Develop a brand story that connects visual choices to strategic meaning

### 2. Typography / Color / Size Specification Generation
- **Color System**: Primary, secondary, and neutral palettes with HEX, RGB, HSL, and CMYK values
- **Typography**: Font families, weights, sizes, line heights, letter spacing for headings and body
- **Spacing & Sizing**: Modular scale, grid system, minimum sizes, safe zones
- **Logo Usage**: Clear space, minimum size, color variants, do's and don'ts

### 3. Application Scenario Extension
- **App Launcher Icon**: iOS/Android icon at multiple resolutions
- **Login Page**: Web/app login screen with brand styling
- **Promotional Materials**: Social media banners, business cards, letterheads, presentation templates
- **Merchandise**: T-shirt, mug, packaging mockups
- **Digital Touchpoints**: Email signatures, favicon, social avatars

### 4. Professional Proposal Document Auto-Layout
- Generate a structured HTML brand guideline document with sections
- Auto-layout specifications in clean, scannable tables and visual examples
- Include visual swatches, type specimens, and usage examples
- Export-ready for client presentation

## Workflow

1. **Brand Audit**: Review existing logo, name, and any brand assets
2. **Concept Definition**: Define brand personality, positioning, and visual direction
3. **System Design**: Build color, typography, spacing, and logo usage rules
4. **Application Mockups**: Generate SVG/HTML mockups for key touchpoints
5. **Guideline Document**: Compile everything into a professional brand book
6. **Delivery**: Output HTML brand guide + individual asset files

## Brand Guide Document Structure

```
1. Brand Overview
   - Brand story & positioning
   - Personality traits & voice
2. Logo System
   - Primary logo, variants, clear space, minimum size
   - Color variants & incorrect usage
3. Color Palette
   - Primary, secondary, neutral colors
   - Usage ratios and accessibility (WCAG contrast)
4. Typography
   - Font families, hierarchy, specimen
5. Spacing & Grid
   - Modular scale, layout grid, safe zones
6. Applications
   - Digital: app icon, web, social
   - Print: business card, letterhead, merchandise
7. Dos & Don'ts
   - Common usage mistakes and corrections
```

## Design Philosophy
- **Consistency over creativity**: A brand system's value is in repeatable rules
- **Document everything**: If it's not specified, it will be done wrong
- **Show, don't just tell**: Visual examples for every rule
- **Plan for misuse**: Explicit "don't" examples prevent common errors
